# Launch Checklist — Agriculture Calculator

## Before upload
- [ ] Extract the ZIP and confirm `index.html` and `assets/` are at the folder root.
- [ ] Confirm the home page lists only 10 featured calculators and links to the full directory.
- [ ] Open the directory and test search plus every category filter.
- [ ] Test every calculator with a hand-checked sample calculation, including zero and edge-case inputs where appropriate.
- [ ] Review crop-specific units, all page FAQs, and the reference links; do not use an estimate to override a label, soil-test recommendation, contract, or legal requirement.
- [ ] Confirm the five articles and the “See more articles” link work.
- [ ] Review About, Contact, Privacy Policy, Terms, Disclaimer, Editorial Policy, and Research and Sources pages.

## Deploy
- [ ] Upload the *contents* of the extracted folder so `index.html` is in the repository root.
- [ ] Enable GitHub Pages or configure Cloudflare Pages with the repository root as the static output directory and no build command.
- [ ] Test the published site on phone and desktop.
- [ ] Submit a test contact form. Complete FormSubmit email activation if requested and confirm actual receipt at `talharaziq@outlook.com` (including Junk).
- [ ] If you add a redirect, set FormSubmit `_next` to the final absolute URL.
- [ ] Replace example/default values only when a crop-appropriate reason and reliable source support them.
- [ ] Add your final domain-specific metadata/canonical setup after the domain is known.
- [ ] Check pages in Google Search Console after deployment. Review index coverage and real search queries when data is available.
