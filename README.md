# Розрахуй — українські онлайн-калькулятори

Production site: <https://agrocalculator.pp.ua/>

This repository builds a static website. The build command must run for every production deployment, and the hosting provider must publish the generated `dist/` directory.

## Required production build settings

- Production branch: `main`
- Root directory: repository root (`/`)
- Build command: `npm run build`
- Build output / publish directory: `dist`
- Node.js: 22 or newer (`.node-version`)

The production domain is defined once in `site.config.mjs`. Canonical URLs, Open Graph URLs, structured-data breadcrumbs, the sitemap, and `robots.txt` all use that value. Do not set a separate `SITE_URL` environment variable.

## What the build does

Every `npm run build`:

1. Rebuilds the generated calculator, category, homepage, about, privacy, and 404 pages.
2. Copies additional static pages from `src/pages/` into the matching paths under `dist/`.
3. Copies articles from `src/articles/` into `dist/articles/`.
4. Runs `sitemap.mjs` as the final build step. It recursively scans the completed `dist/` tree, fixes canonical and Open Graph URLs to the production domain, writes `dist/sitemap.xml`, and writes `dist/robots.txt` with the sitemap address.

The sitemap does not use a manually maintained list of calculator slugs or page URLs. It finds indexable HTML files in the final output, so new generated calculator pages and new HTML pages/articles are included automatically on the next successful build and deployment. Pages with a `noindex` robots meta tag and the 404 page are excluded.

A static site cannot change its deployed sitemap before a new build is deployed. Adding content to the repository triggers the normal deployment; the sitemap is generated as part of that deployment's build.

## Add content

### Calculator

1. Add a calculator entry to the `calculators` array in `src/catalog.json`.
2. Implement its calculation `type` in `public/app.js`.
3. Run `npm run build`. The generated calculator HTML and sitemap entry are created together.

### Regular page

Add an HTML file under `src/pages/`. The path is preserved in the published site:

- `src/pages/contact/index.html` becomes `/contact/`.
- `src/pages/tools/guide.html` becomes `/tools/guide.html`.

### Article

Add an HTML file under `src/articles/`. The path is published below `/articles/`:

- `src/articles/wheat-yield/index.html` becomes `/articles/wheat-yield/`.
- `src/articles/soil-testing.html` becomes `/articles/soil-testing.html`.

Use root-relative asset paths such as `/assets/site.css` in these pages. Do not create a custom page at a path already generated by the calculator builder; the build stops with an error instead of silently overwriting it.

## Local preview

```bash
npm run build
npm run serve
```

Open `http://localhost:4173/`.

## Relevant source files

- `site.config.mjs` — single production-domain setting.
- `build.mjs` — generates the site and invokes the sitemap generator.
- `sitemap.mjs` — normalizes site metadata and generates the sitemap and robots file from final HTML output.
- `package.json` — build and preview commands.
- `src/catalog.json` — calculator catalogue.
- `src/pages/` — additional static pages.
- `src/articles/` — article pages.
- `public/app.js` — calculator logic and catalogue search.
- `public/site.css` — site styles.
- `dist/` — generated output; do not edit it by hand.

## Limits

- Currency rates are entered by the visitor; the site does not fetch live rates.
- Tax rates, tariffs, bank conditions and other changeable values should be checked before use.
- Health calculators provide general estimates, not medical conclusions.
